# جستجوگر طرح — نسخهٔ اندروید (PatternFinder Android)

همان موتور نسخهٔ ویندوز (پایتون + OpenCV + SQLite) داخل یک برنامهٔ اندروید، با رابط لمسی تازه. بدون نیاز به کامپیوتر اجرا می‌شود.

## امکانات (هم‌ارز نسخهٔ ویندوز)
* **کتابخانه:** انتخاب پوشه، اسکن بازگشتی و افزایشی، تشخیص فایل خراب/تکراری، تشخیص خودکار قطعات
* **ویرایش قطعات:** مستطیل / چندضلعی / حذف / جایگزینی، زوم و جابه‌جایی، ۶ روش پیش‌پردازش + قطبیت زمینه، نمایش باینری، «تأیید»، «تأیید و بعدی»، «تأیید همهٔ در انتظار»
* **جستجو:** تصویر پرسش از گالری ← انتخاب/کشیدن قطعه ← جستجوی قطعه یا ترکیبی ← جستجوی عمیق اختیاری
* **نتایج:** امتیاز و تفکیک شکل/خطوط/هندسه/چیدمان، نمایش تصویر مادر با کادر قرمز روی محل قطعه (قابل زوم)
* **تنظیمات:** وزن‌ها، تعداد نتایج، بازرتبه‌بندی، جستجوی عمیق، تعداد Thread؛ آزمون سلامت موتور و نمایش گزارش خطا

## ساخت APK با GitHub (بدون کامپیوتر)
### راه الف — فقط از گوشی (پیشنهادی)
1. در GitHub یک مخزن (Repository) جدید بسازید (می‌تواند Private باشد).
2. **Add file ← Create new file**؛ نام فایل را دقیقاً `.github/workflows/build-from-zip.yml` بگذارید و محتوای فایل هم‌نام داخل همین بسته را در آن Paste کنید ← Commit.
3. **Add file ← Upload files** ← فایل `PatternFinder-Android.zip` را (همان‌طور که هست، بدون باز کردن) آپلود و Commit کنید.
4. تب **Actions ← Build APK from zip** (اگر خودکار شروع نشد: Run workflow). حدود ۱۰ تا ۲۰ دقیقه صبر کنید.
5. پس از سبز شدن، همان اجرا را باز کنید ← پایین صفحه در بخش **Artifacts** فایل `PatternFinder-APK` را دانلود کنید ← از zip خارج کنید ← `app-debug.apk` را نصب کنید.

### راه ب — با Git یا آپلود پوشه (از کامپیوتر)
محتوای zip را در ریشهٔ مخزن بگذارید (فایل `.github/workflows/build.yml` همراه بسته است). با هر push، APK ساخته می‌شود.

> نصب: «نصب از منابع ناشناس» را برای مرورگر/مدیر فایل فعال کنید. APK با کلید debug امضا می‌شود (برای استفادهٔ شخصی کافی است).

## اولین اجرا
1. برنامه دسترسی **«مدیریت همهٔ فایل‌ها»** را می‌خواهد (برای خواندن مستقیم پوشهٔ تصاویر)؛ در صفحهٔ تنظیمات روشنش کنید و برگردید. اجازهٔ اعلان را هم بدهید (برای پردازش پس‌زمینه).
2. **تنظیمات ← آزمون موتور** را بزنید؛ باید «✅ موفق» ببینید.
3. تب «کتابخانه» ← انتخاب پوشه ← اسکن ← (ویرایش/تأیید) ← تب «جستجو».

نکتهٔ باتری: برای کتابخانهٔ بزرگ، شارژر را وصل کنید و برنامه را از «بهینه‌سازی باتری» مستثنا کنید. اسکن اولیهٔ ۱۰٬۰۰۰ تصویر روی گوشی ممکن است ساعت‌ها طول بکشد (فقط یک بار؛ بعد افزایشی است). در هر مرحله می‌توانید «لغو» بزنید و بعداً ادامه دهید.

## وضعیت راستی‌آزمایی (صادقانه)
* **تأییدشده:** لایهٔ پایتون (پل `bridge.py` + موتور) روی داده مصنوعی به‌صورت کامل اجرا و تست شد (اسکن، ویرایش، تأیید، جستجوی قطعه/ترکیبی، پیش‌نمایش).
* **تأییدنشده:** کد Kotlin/Compose و ساخت APK در محیط من قابل کامپایل نبود (بدون اینترنت و بدون Android SDK). ممکن است ساخت اول خطای کوچک بدهد. اگر چنین شد، **متن خطای مرحلهٔ Build** را بفرستید تا اصلاح کنم.
* نسخهٔ OpenCV/NumPy را Chaquopy خودش انتخاب می‌کند (ممکن است قدیمی‌تر از نسخهٔ ویندوز باشد، ولی APIهای مورد استفاده سازگارند).
* دقت اندازه‌گیری‌شده روی داده مصنوعی همان نتایج README ویندوز است؛ دقت واقعی را فقط با نمونه‌های خودتان می‌توان سنجید.

## ساختار
```
app/src/main/python/     موتور (image_engine, database, config) + bridge.py (پل) + tools/synthetic.py (آزمون)
app/src/main/java/...    رابط Kotlin/Compose (کتابخانه، ویرایشگر، جستجو، نتایج، تنظیمات)
.github/workflows/       build.yml (ساخت از پوشه) و build-from-zip.yml (ساخت از zip)
```
داده‌ها (پایگاه داده، تنظیمات، لاگ) در حافظهٔ خصوصی برنامه ذخیره می‌شوند و با حذف برنامه پاک می‌شوند.
